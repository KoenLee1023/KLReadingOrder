## 概覽

引擎先移除修剪後為空的候選，依頁碼升序分組，再為每頁判斷方向。橫排使用字形高度中位數、中心距離與基線重疊分群。直排使用字形寬度中位數分群。最後依閱讀方向排序成員、合併矩形、串接文字並計算信心值算術平均。

## 行為保證

- 橫排由上至下、行內由左至右
- 直排按欄由右至左、欄內由上至下
- 每頁獨立自動判斷方向
- 依字形中位幾何調整容差
- 多頁排序、合併邊界、平均信心值與來源 ID

## 職責邊界

不執行 OCR、校正傾斜、旋轉、透視修正、信心值篩選、語言辨識、表格擷取或文件語意。每頁所有框必須使用同一正規化座標系。

API 只回傳計算結果，不會修改整合端 App 的狀態。輸入、設定與系統框架行為相同時，結果也會保持一致。
