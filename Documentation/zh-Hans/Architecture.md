# KLReadingOrder 架构

## 概览

引擎先删除修剪后为空的候选，按页升序分组，再为每页解析方向。横排使用字符高度中位数、中心距离与基线重叠聚类。竖排使用字符宽度中位数聚类。最后按阅读方向排序成员，合并矩形、连接文本并求置信度算术平均。

## 行为保证

- 横排从上到下、行内从左到右
- 竖排按列从右到左、列内从上到下
- 每页独立自动判断方向
- 基于中位字符几何的自适应容差
- 多页排序、合并边界、平均置信度和来源 ID

## 职责边界

不执行 OCR、纠偏、旋转、透视校正、置信度过滤、语言识别、表格提取或文档语义。每页所有框必须使用同一归一化坐标系。

API 只返回计算结果，不会修改接入应用的状态。在输入、配置和系统框架行为一致时，结果保持一致。
