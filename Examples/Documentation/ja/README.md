# KLReadingOrder デモアプリ

> <span lang="ja">[English](../en/README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)</span>

KLReadingOrder は、文字列、信頼度、正規化した矩形、ページ番号、元の並び順を受け取り、読み順にまとめた行を返す Swift パッケージです。OCR 自体や文章の意味解析は行わず、認識結果を読みやすい順番へ並べる処理だけを担当します。

## Reading Flow

左下原点の正規化キャンバスに 6 個の合成候補を表示し、既定のエンジンが再構成した横書きの行を一覧にします。順不同の入力、行への分類、行内の左から右への並び、区切り文字の指定、正規化座標から SwiftUI の左上原点キャンバスへの変換を確認できます。入力は 1 ページだけで、候補 ID は表示しません。

## Layout Comparator

同じ 4 個の候補に対して、横書きと縦書きをそれぞれ明示的に指定します。2 つの結果領域には、結合後の文字列とメンバー ID が表示されます。自動判定は実行せず、ポリシー値を操作する機能もありません。

どちらのデモにも専用の `Package.swift` とアプリのエントリポイントがあります。リポジトリ直下のパッケージだけに依存し、wondays のコードやリソースは読み込みません。

このパッケージは、OCR、傾きや回転の補正、遠近補正、信頼度による除外、言語判定、表の抽出、文章の意味解析を行いません。同じページに含まれる矩形は、必ず同じ正規化座標系で渡してください。
