# KLReadingOrder 데모 앱

> <span lang="ko">[English](../en/README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)</span>

KLReadingOrder는 문자열, 신뢰도, 정규화된 사각형, 페이지 번호, 원래 입력 순서를 받아 읽기 순서로 묶은 행을 반환하는 Swift 패키지입니다. OCR 자체나 문서의 의미를 분석하지 않고 인식 결과를 읽기 좋은 순서로 정리하는 작업만 담당합니다.

## Reading Flow

왼쪽 아래가 원점인 정규화 캔버스에 합성 후보 여섯 개를 표시하고 기본 엔진이 재구성한 가로쓰기 행을 보여 줍니다. 뒤섞인 입력, 행 분류, 행 안의 왼쪽에서 오른쪽 순서, 사용자 지정 구분자, 정규화 좌표를 SwiftUI의 왼쪽 위 원점 캔버스로 변환하는 과정을 확인할 수 있습니다. 한 페이지만 사용하며 후보 ID는 표시하지 않습니다.

## Layout Comparator

같은 후보 네 개에 가로쓰기와 세로쓰기를 각각 강제로 적용합니다. 두 결과 영역에는 결합된 문자열과 구성원 ID가 표시됩니다. 자동 방향 판정은 실행하지 않으며 정책 값을 조절하는 기능도 없습니다.

두 데모 앱에는 각각 전용 `Package.swift`와 앱 진입점이 있습니다. 저장소 루트의 패키지만 사용하며 wondays 코드나 리소스를 가져오지 않습니다.

이 패키지는 OCR, 기울기 및 회전 보정, 원근 보정, 신뢰도 필터링, 언어 감지, 표 추출, 문서 의미 분석을 수행하지 않습니다. 같은 페이지에 있는 모든 사각형은 반드시 동일한 정규화 좌표계를 사용해야 합니다.
